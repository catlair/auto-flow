# 江湖悬赏：抢单 → 完成 全流程记录

> 真机截图整理，2026-10-22。前半段（抢单）已自动化，见 `bounty-grab.json`；
> 后半段（接取之后怎么完成）**尚未自动化**，先把界面与判据记下来。

## 阶段一：抢单（已自动化）

```
大世界 → 鼠标移到右上角图标（浮出「菜单」提示）→ 点一下 → 面板展开
  → 面板向下滚（**按像素、正值**才滚得动；负值是往上滚，按行滚完全没反应）
  → 点「悬赏」→ 江湖悬赏界面 → 点「营生」分类
  → 循环：点「刷新」→ 有「解决诬陷」就点它 → 点「接取悬赏」
        → 抢失败有两条提示：「当前悬赏已被其他少侠领取」/「该悬赏已失效」
        → 失败就直接刷新换一批（刷新后列表变了，下次点的就是别的悬赏）
```

已量出来的数：菜单图标 `窗口右上角 (-23, +48)`；滚动 `win_tr (-150,+320)`、
`scroll_unit=pixel`、`scroll_dy=+2000`；页面判据用「玩法说明」（「江湖悬赏」是书法字，OCR 读不出来）。

### 键位

这个游戏**不认合成字符按键、认虚拟键码**（`vk:`）：

| 按键 | 写法 | 备注 |
| --- | --- | --- |
| Space | `vk:49` | 「前往」「开始话术」「继续」 |
| F | `vk:3` | 「诬陷悬赏」交互、「快速话术」 |
| Esc | `vk:53` | 观战/复活点那个退出图标不是 Esc，别混 |
| R | `vk:15` | 刷新（已实测可用） |

### 抢单失败的提示（真机）

点完「接取悬赏」**立刻**在屏幕中间弹一行字：

```
当前悬赏已被其他少侠领取
请勿频繁领取悬赏
```

两件事：① 失败判据是「已被其他少侠领取」，不是「已失效」（后者是另一种情况，超时才出现）；
② 「请勿频繁领取」说的是**别反复点同一个悬赏**，不是全局频率限制——所以不用加冷却，
失败后直接刷新换一批，下次点到的就是别的悬赏。

失败有三种：「其他少侠领取」「请勿频繁领取」「该悬赏已失效」。
**失效这种要特殊处理**：失效的悬赏会一直占着右侧详情面板，再点接取永远还是「已失效」。
所以要先点面板右上角的收起箭头（`«`，窗口右上角 -30,+44）清掉选中状态，再刷新，才选得到别的。
