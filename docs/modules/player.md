## 设计要点

1. **插值算法**（Tauri 版验证过的遗产）：步数 = ceil(dist/10) 夹 [1,120]，若预算
   允许再夹到 budget/8ms；步间等待 = budget/steps 夹 [8ms, 50ms]。
2. **点击时序**（2026-09-12 修复）：鼠标事件的预算只被「滑行」消耗，若光标已在
   目标位置（点击场景），预算无人消费 → press/release 挤在上一事件后立刻发出，
   与录制时序脱节，应用不认这种瞬时点击。修复：距离 <1px 时先 `_wait(budget)`
   再执行。
3. **中断安全**：播放循环包 try/finally，held_button 与 pressed_keys 逐一补
   release——否则 F10 停止时鼠标键/键盘卡在按下状态。
4. **时间基准**：绝对事件时间（ts_ms/speed），不用逐事件 delta 累加——漂移不累积。

## 已知问题

- 播放中若用户手动抢鼠标，轨迹会跟上真实光标重新出发（未做独占）。
- 长距离快速移动在低速机器上可能低于 8ms/步的下限，尾段轻微跳变。
